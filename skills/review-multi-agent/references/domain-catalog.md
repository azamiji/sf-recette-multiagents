# Catalogue de rôles par domaine

Réservoir pour compléter les personas issus de l'org (règle 3 de `persona-generation.md`). Ce ne sont pas des listes à copier : on n'y prend que les rôles qui touchent le périmètre et que l'org ne porte pas déjà. Le CEO est implicite partout.

Pour un domaine absent de ce catalogue, raisonne de la même façon : chaîne de valeur du métier (vendre → produire/servir → facturer → encaisser → après-vente), fonctions de contrôle, acteurs externes.
